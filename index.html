📖 GAME RULES

  1. Classic contains 10 questions.
  2. Each Classic question has a 10–15 second timer.
  3. Hard contains Currency and Region questions.
  4. Extreme adds Population and Area.
  5. Nightmare uses all available knowledge.
  6. Ambiguous Currency/Region questions use multiple clues.
  7. Bosses have HP and require correct answers to damage them.
  8. Items are activated from the Item Bar.
  9. Time Freeze freezes the timer for 5 seconds.
  10. Time Freeze cannot be activated while already frozen.
  11. Boss-exclusive items have special effects.
  12. Chest rarity affects rewards.
  13. Transcendent Chests are extremely rare.
  14. Owner tools are available only to the game owner.
